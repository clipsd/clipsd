- 截图后立即按 Alt+W 时，“版本新功能”窗口不再出现在选取窗口上方：等您完成后再出现。
- 从手机。截图正在关闭时（“截图未保存”提问打开时）收到的照片不再丢失：它会作为单独的截图打开。手机发来的每张照片都会立即保存到截图文件夹（若已开启自动保存），即使它已放入打开的截图中。
- 选取窗口。对同一截图再次点“保存”不再生成相同的文件：会显示“已经保存”和文件名。按住 Ctrl+S 也只保存一次。
- Windows。“已打开的窗口 ▾”列表不再等待网络驱动器：网络驱动器上的程序显示字母而非图标。
- 调色板旁的提示不再比以前宽：长的一行会换到第二行。
- 编辑器中的“从手机”按钮可用键盘（Tab）到达。
- “版本新功能”窗口会随程序一起切换语言。
- 修正了乌克兰语、中文、西班牙语、英语、葡萄牙语和土耳其语的翻译。
- Windows。图片中的俄语文字不再变成拉丁字母。如果 Windows 没有俄语文字识别，程序会提供“安装识别”按钮来安装。
- Windows。安全：文字识别现在直接由 Windows 程序 DISM 安装，不再使用 PowerShell；在 Windows 请求权限之前，程序会说明请求针对哪个 Microsoft 程序（DISM 或 Windows PowerShell）：这是正常的，请点击“是”。
